How it fits

Name or photo the bike. Confirm it. Pick a part. Open the factory page. Follow those pages. Get the part.

What you do

flowchart LR
  A[Name or photo] --> B[Is this the bike?]
  B -->|No| A
  B -->|Yes| C[Which part?]
  C --> D[Open the book]
  D --> E[Follow the pages]
  E --> F[Quote, buy, used, invoice]

How the system is built

flowchart TB
  subgraph In["Phone"]
    CAM[Camera or typed model]
    ID[Identity match]
    UI[Factory page on screen]
    INV[Parts and invoice]
  end
  subgraph Store["Manuals store — MongoDB"]
    PDF[Verbatim shop manuals]
  end
  subgraph Find["Query layer — Elasticsearch"]
    Q[Page, section, figure lookup]
  end
  CAM --> ID
  ID --> Q
  Store --> Q
  Q --> UI
  UI --> INV

MongoDB holds the manuals. Elasticsearch finds the page. The app never replaces the book with generated repair text.
